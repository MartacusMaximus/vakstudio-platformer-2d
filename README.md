Simple Platformer game for artists to implement their own characters

Comes with the following:
Puppet Character with the following functionality:
  Basic Movement and Jumping
  Combat (3-hit combo when pressing 'Q')
  
Sprite Based Character with the following functionality:
  Basic Movement and Jumping
  Combat (3-hit combo when pressing 'Q')

Functionality to come:

  Doors
